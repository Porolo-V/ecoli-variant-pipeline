# Пайплайн поиска вариантов у E. coli

[🇬🇧 English](README.md) | 🇷🇺 Русский [![pipeline-test](https://github.com/Porolo-V/ecoli-variant-pipeline/actions/workflows/ci.yml/badge.svg)](https://github.com/Porolo-V/ecoli-variant-pipeline/actions/workflows/ci.yml)

Воспроизводимый пайплайн для коротких ридов: сырые риды Illumina → отфильтрованные аннотированные варианты.
Первый, намеренно простой случай: *E. coli* B REL606 (гаплоид, 4,6 Мб).

## Схема

```mermaid
flowchart LR
  A[FASTQ] --> B[fastp<br/>очистка]
  B --> C[BWA-MEM2<br/>выравнивание]
  C --> D[samtools<br/>удаление дубликатов]
  D --> E[bcftools<br/>mpileup + call]
  E --> F[bcftools filter<br/>QUAL, DP, MQ]
  F --> G[snpEff<br/>аннотация]
  G --> H[таблица вариантов]
```

Две реализации одного и того же анализа:
- `scripts/run_all.sh`: обычный bash-скрипт (дополнительно запускает FastQC/MultiQC и скачивает данные).
- `main.nf` + `nextflow.config`: версия на Nextflow (6 процессов) с тестовым профилем `test`.

## Быстрый старт

```bash
mamba env create -f environment.yml
conda activate varcall

# быстрый тест на участке 300 тыс. п.н. (несколько минут)
nextflow run main.nf -profile test

# полный запуск (скачивает данные и выполняет все шаги)
bash scripts/run_all.sh
```

## Данные

- Риды: SRR2584863 (парные риды Illumina, эволюционный эксперимент на E. coli), скачаны из ENA.
- Референс: NC_012967.1 (E. coli B str. REL606), FASTA и GenBank из NCBI.

## Результаты (полный образец, bash-версия)

| Шаг | Результат |
|---|---|
| Риды до и после fastp | 3,10 млн / 2,57 млн (осталось 82,8%; Q30 = 94,4%) |
| Причина потерь | 17,2% ридов стали слишком короткими после обрезки хвостов, 0,04% низкое качество |
| Выравнивание | 100% mapped, 98,2% properly paired |
| Удалено дубликатов | ~1% |
| Средняя глубина / охват генома | 73x / 99,85% |
| Варианты | 30 сырых → 26 (QUAL>30, DP>10) → **22** (MQ>40) |

Из 22 вариантов: 13 missense, 3 со сдвигом рамки, 1 вставка без сдвига рамки, 5 вне генов (рядом с ними).
Полная таблица: [`docs/variants_table.tsv`](docs/variants_table.tsv).

## Решения по фильтрации

Четыре варианта (позиции 263235, 377000, 2407766, 2618472) прошли фильтры QUAL и DP, но у них
MQ 22-30, у 23-39% ридов MQ=0, а риды разделились между референсной и новой буквой (DP4).
Для гаплоидного организма это нетипично. Вероятно, это повторяющиеся участки, где сходятся
риды из нескольких копий, поэтому фильтр по качеству выравнивания (MQ>40) их убирает.
Тестовый набор это проверяет: позиция 263235 должна быть в сыром VCF и отсутствовать после фильтрации.

## Ограничения

- Один образец, нет независимой проверки (например, в IGV или секвенированием по Сэнгеру).
- Пороги подобраны по этому образцу, а не проверены на эталонном наборе.
- Позиция 2103887 (вставка в тандемном повторе, глубина 28) оставлена, но с низкой уверенностью.
- Индели в гомополимерах и повторах менее надёжны при коротких ридах.
- В таблице берётся первая запись `ANN` из snpEff, поэтому межгенные варианты могут отображаться как `upstream_gene_variant`.
- `--ploidy 1` жёстко прописан в вызове вариантов; для других организмов нужны параметры (в планах).
- Nextflow-версия проверена на подмножестве 300 тыс. п.н., в том числе на двух образцах параллельно (на полном образце пока нет).
- Базовый образ `mambaorg/micromamba:latest` не закреплён, а зависимости инструментов (например, openjdk, python) не закреплены по отдельности; фактические версии записаны в `docs/image_packages.txt`.
- `bwa-mem2` установлен как пакет версии 2.3, но программа сообщает 2.2.1 (так же и в исходном окружении conda); в README записана версия пакета.

## Проблемы и решения

- Медленные соединения с GitHub/NCBI/ENA: решено многопоточной загрузкой (`aria2c -x 8`) с ENA.
- В FastQC 0.13 вместо `-o` используется `--outdir`.
- Правило `.gitignore` `data/` случайно исключило и `tests/data`; исправлено привязкой к корню (`/data/`).
- При нескольких образцах после выравнивания обрабатывался только один: каналы с одиночными файлами (референс, индекс) по умолчанию расходуются. Исправлено value-каналами и проверено запуском на двух образцах.

## Структура репозитория

```
main.nf, nextflow.config   пайплайн на Nextflow и параметры
scripts/run_all.sh         bash-версия всего анализа
tests/data/                подмножество ридов 300 тыс. п.н. и референс для профиля test
docs/                      таблица вариантов, список пакетов образа, рисунки
environment.yml            окружение conda
Dockerfile                 образ с инструментами для процессов Nextflow
.github/workflows/ci.yml   CI: сборка образа, тест, проверка вариантов
```

## Docker и CI

Инструменты, которые запускают процессы Nextflow (fastp, bwa-mem2, samtools, bcftools, snpEff), собраны в образ Docker из `Dockerfile`; версии пяти инструментов закреплены по тем, что использовались для результатов. Полный список пакетов лежит в [`docs/image_packages.txt`](docs/image_packages.txt).

    docker build -t ecoli-varcall:0.2 - < Dockerfile
    nextflow run . -profile test,docker

GitHub Actions (`.github/workflows/ci.yml`) собирает образ и запускает тестовый профиль при каждом пуше. Проверяется результат, а не только завершение запуска: в отфильтрованном VCF должны быть ровно позиции 9972 и 281923, а позиция 263235 должна присутствовать в сыром VCF и убираться фильтром по MQ. Тест самодостаточен (референс лежит в `tests/data/ref`).
